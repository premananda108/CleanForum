# Протокол изменений

## [Не выпущено]

### Добавлено
- **Редактирование постов:** Авторы теперь могут редактировать свои собственные посты. Добавлена страница редактирования и соответствующая логика на бэкенде и фронтенде.
- **Удаление постов модератором:** В панель модератора добавлена возможность "мягкого" удаления постов.
- **Современный текстовый редактор:** Стандартное поле для ввода текста заменено на современный блочный редактор Editor.js, который сохраняет контент в безопасном формате JSON.

### Изменено
- **Логика обработки спама:**
    - Посты и комментарии, определенные как спам, больше не сохраняются в базу данных. Вместо этого API возвращает ошибку `422 Unprocessable Entity`.
    - **Исправлена система обратной связи:** Теперь, когда модератор помечает контент как спам или одобряет его, соответствующая метка (`label`) в векторной базе данных Redis немедленно обновляется. Это позволяет системе в реальном времени учиться на действиях модератора и улучшать качество детекции спама.
- **Интерфейс модератора:**
    - В панели модератора (`/moderator`) блоки "Статистика контента" и "Комментарии на модерации" поменялись местами для более удобного доступа.
- **Визуальный стиль:**
    - Обновлена цветовая схема сайта на зелено-золотую. Изменения применены к базовому шаблону (`base.html`) и главной странице (`index.html`).
