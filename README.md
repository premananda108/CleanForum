# CleanForum

# 🛡️ Форум с продвинутой анти-спам системой

Современный форум на базе **FastAPI** и **Redis 8** с интеллектуальной системой защиты от спама, использующей машинное обучение и анализ поведения пользователей.

## ✨ Основные возможности

### 🔒 Анти-спам система
- **Bayesian фильтрация** - Наивный байесовский классификатор для определения спама
- **ML-модели** - Машинное обучение с использованием scikit-learn
- **Анализ поведения** - Отслеживание паттернов активности пользователей
- **Rate limiting** - Ограничение частоты публикаций
- **IP репутация** - Система оценки надежности IP-адресов
- **Детекция ботов** - Автоматическое обнаружение автоматизированных аккаунтов
- **Автообучение** - Постоянное улучшение модели на основе обратной связи

### 🚀 Технические особенности
- **FastAPI** - Современный, быстрый веб-фреймворк
- **Redis 8** - Высокопроизводительная база данных в памяти
- **Асинхронность** - Полная поддержка async/await
- **REST API** - Полноценное API для интеграции
- **Веб-интерфейс** - Современный интерактивный интерфейс
- **Docker** - Готовые контейнеры для развертывания
- **Мониторинг** - Подробная статистика и логирование

## 🛠️ Установка и настройка

### Требования
- Python 3.11+
- Redis 8.0+

1. **Клонирование и установка зависимостей:**
```bash

pip install -r requirements.txt
```

2. **Запуск Redis:**


4. **Запуск форума:**
```bash

```

5. **Открыть в браузере:**


## 🧠 Алгоритмы анти-спам системы

### 1. Bayesian фильтрация

Использует теорему Байеса для вычисления вероятности того, что текст является спамом:

```
P(spam|words) = P(words|spam) * P(spam) / P(words)
```

**Особенности:**
- Сглаживание Лапласа для обработки новых слов
- Инкрементальное обучение
- Поддержка многоязычности

### 2. ML-модели

**TF-IDF + Multinomial Naive Bayes:**
- Векторизация текста с помощью TF-IDF
- Классификация через Multinomial Naive Bayes
- Онлайн-обучение с partial_fit

### 3. Анализ поведения

**Отслеживаемые метрики:**
- Частота публикаций
- Временные паттерны активности
- Разнообразие словаря
- История смены IP
- Длина и структура постов

### 4. Rate Limiting

**Алгоритм скользящего окна:**
- Максимум 5 постов за 5 минут на пользователя
- Максимум 10 постов за 5 минут с одного IP
- Автоматическая очистка старых записей

### 5. IP репутация

**Система оценок:**
- Начальная репутация: 50/100
- Штраф за спам: -10 баллов
- Награда за качественный контент: +1 балл
- Время жизни репутации: 7 дней

## 🚀 Производительность

### Оптимизации

1. **Кэширование результатов** анализа спама
2. **Batch-обработка** для массовых операций
3. **Асинхронные операции** для всех I/O
4. **Connection pooling** для Redis
5. **Lazy loading** для ML-моделей

### Масштабирование

- **Горизонтальное**: Несколько экземпляров приложения
- **Вертикальное**: Увеличение ресурсов Redis
- **Sharding**: Разделение данных по forum_id
- **Load balancing**: Nginx или HAProxy

## 🛡️ Безопасность

### Меры защиты

- **Rate limiting** на уровне приложения
- **Input validation** через Pydantic
- **SQL injection** защита (Redis NoSQL)
- **XSS protection** в веб-интерфейсе
- **CORS** настройки для API

### Рекомендации

1. Использовать **HTTPS** в продакшене
2. Настроить **firewall** для Redis
3. Включить **аутентификацию** Redis
4. Регулярно **обновлять** зависимости
5. Мониторить **подозрительную активность**

## 📝 Известные ограничения

1. **Память**: ML-модели требуют дополнительной памяти
2. **Языки**: Оптимизировано для русского и английского
3. **Cold start**: Первые запросы могут быть медленнее
4. **False positives**: Возможны ложные срабатывания на новых темах
