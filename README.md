# CleanForum

Простой веб-форум с автоматической модерацией спама на основе машинного обучения.

## 🚀 Особенности

- **Публикация сообщений**: Пользователи могут добавлять сообщения на форум.
- **Классификация спама**: Каждое новое сообщение автоматически проверяется на спам.
- **Обучение модели**: Возможность обучать модель детекции спама на собственном наборе данных.

## 🛠️ Технологический стек

- **Backend**: Python, FastAPI
- **База данных**: Redis
- **Машинное обучение**: Scikit-learn, NLTK
- **Оркестрация**: Docker, Docker Compose

## ⚙️ Установка и запуск

Для запуска проекта требуется установленный Docker и Docker Compose.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL_репозитория>
    cd CleanForum
    ```

2.  **Обучите модель (первый запуск):**
    Перед первым запуском веб-сервиса необходимо создать файлы модели. Запустите скрипт обучения:
    ```bash
    python core/training.py
    ```
    *Примечание: Убедитесь, что у вас установлены зависимости из `requirements.txt` (`pip install -r requirements.txt`) или выполните команду в виртуальном окружении.*

3.  **Запустите сервисы с помощью Docker Compose:**
    ```bash
    docker-compose up -d --build
    ```
    Эта команда соберёт образ для веб-приложения и запустит все необходимые сервисы (веб-сервер и базу данных Redis) в фоновом режиме.

## 🌐 Использование

-   **Веб-интерфейс форума** будет доступен по адресу: `http://localhost:8000/`
-   **Добавление сообщения**: Отправьте POST-запрос на `http://localhost:8000/add_message` с JSON-телом:
    ```json
    {
      "text": "Это ваше сообщение."
    }
    ```
-   **Получение сообщений**: Отправьте GET-запрос на `http://localhost:8000/get_messages` для получения списка всех сообщений, не являющихся спамом.

## 🧠 Обучение модели

Модель классификации спама обучается на данных из файла `spam_dataset.json`. Вы можете изменять этот файл для обучения на собственных данных.

Для повторного обучения модели выполните команду:
```bash
python core/training.py
```
После выполнения скрипта будут созданы/обновлены файлы `model.pkl` и `vectorizer.pkl`. Для того чтобы изменения вступили в силу, необходимо перезапустить Docker-контейнер веб-приложения:
```bash
docker-compose restart web
```
