
# Техническое Задание: Схема Данных в Redis

Дата: 02.08.2025
Версия: 1.0

Этот документ описывает структуру и назначение ключей, используемых в базе данных Redis для проекта CleanForum. Он служит техническим заданием для разработчиков, чтобы обеспечить консистентность данных.

---

## 1. Основной Объект Поста

Хранит полную информацию о посте. Является **источником правды** для отображения на страницах.

- **Шаблон Ключа:** `post:<uuid>`
- **Тип:** `HASH`
- **Пример Ключа:** `post:a1b2c3d4-e5f6-7890-1234-567890abcdef`

### Поля (Fields):

| Поле             | Тип Данных | Описание                                                                  |
|------------------|------------|---------------------------------------------------------------------------|
| `id`             | `string`   | UUID поста, дублирует часть ключа.                                        |
| `title`          | `string`   | Полный заголовок поста.                                                   |
| `content`        | `string`   | **Чистый текст** поста (без JSON), извлеченный из Editor.js. Используется для SEO и превью. |
| `content_json`   | `string`   | **Исходный JSON** от Editor.js для рендеринга в редакторе и на странице. |
| `category_id`    | `string`   | UUID категории, к которой принадлежит пост.                               |
| `author_id`      | `string`   | UUID автора поста.                                                        |
| `tags`           | `string`   | JSON-массив строк с тегами, например `["python", "redis"]`.              |
| `status`         | `string`   | Статус поста: `published`, `draft`, `moderated`, `spam`, `deleted`.       |
| `created_at`     | `string`   | Дата создания в формате ISO 8601.                                         |
| `updated_at`     | `string`   | Дата последнего обновления в формате ISO 8601.                             |
| `view_count`     | `integer`  | Счетчик просмотров.                                                       |
| `comment_count`  | `integer`  | Счетчик комментариев.                                                     |
| `vote_score`     | `integer`  | Рейтинг поста (сумма голосов).                                            |
| `is_spam`        | `string`   | Флаг спама: `"True"` или `"False"`.                                       |
| `spam_score`     | `float`    | Оценка спама от 0.0 до 1.0.                                               |
| `reading_time`   | `integer`  | Расчетное время чтения в минутах.                                         |

---

## 2. Индексный Объект Поста (для Поиска)

Хранит данные, предназначенные **исключительно для поискового движка RediSearch**. Создается и обновляется параллельно с основным объектом поста.

- **Шаблон Ключа:** `vector:post:<uuid>`
- **Тип:** `HASH`
- **Пример Ключа:** `vector:post:a1b2c3d4-e5f6-7890-1234-567890abcdef`
- **Важно:** Этот ключ индексируется RediSearch согласно правилу `PREFIX` в схеме индекса.

### Поля (Fields):

| Поле      | Тип Данных (в Redis) | Описание                                                                  |
|-----------|----------------------|---------------------------------------------------------------------------|
| `vector`  | `binary`             | Бинарный вектор (embedding) поста для векторного поиска.                   |
| `title`   | `string` (TEXT)      | Заголовок поста для полнотекстового поиска.                               |
| `content` | `string` (TEXT)      | Чистый текст поста для полнотекстового поиска.                            |
| `doc_id`  | `string`             | UUID поста без префиксов для обратной связи.                              |

---

## 3. Списки и Множества (для Связей и Сортировки)

Эти структуры используются для быстрого получения списков постов без необходимости сканирования всей базы.

- **Все посты (сортировка по времени):**
  - **Ключ:** `posts:all`
  - **Тип:** `SORTED SET`
  - **Значение:** `post_id`
  - **Оценка (Score):** `timestamp` создания поста.

- **Посты по категориям:**
  - **Ключ:** `posts:category:<category_id>`
  - **Тип:** `SORTED SET`

- **Посты по авторам:**
  - **Ключ:** `posts:author:<author_id>`
  - **Тип:** `SORTED SET`

- **Посты, помеченные как спам:**
  - **Ключ:** `posts:spam`
  - **Тип:** `SET`

---

## 4. Объект Категории

- **Шаблон Ключа:** `category:<uuid>`
- **Тип:** `HASH`

### Поля (Fields):

| Поле        | Тип Данных | Описание                               |
|-------------|------------|----------------------------------------|
| `id`        | `string`   | UUID категории.                        |
| `name`      | `string`   | Название категории.                    |
| `description`| `string`   | Описание категории.                    |
| `post_count`| `integer`  | Количество постов в этой категории.    |
| `color`     | `string`   | Цвет категории в HEX (например, `#FF5733`). |

---

## 5. Поисковый Индекс

- **Имя индекса:** `forum_posts_index` (задается в `config.py`)
- **Индексируемые префиксы:** `vector:post:`, `vector:comment:`
- **Схема:**
  - `vector`: VECTOR (HNSW)
  - `title`: TEXT
  - `content`: TEXT
