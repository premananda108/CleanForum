# Техническое Задание: CleanForum

**1. Общее описание**

**CleanForum** — это современный и минималистичный веб-форум, разработанный на Python с использованием фреймворка FastAPI. Ключевой особенностью проекта является встроенная система автоматической модерации контента (фильтрации спама) на основе векторного анализа текста. Проект спроектирован с нуля по современным стандартам качества, с акцентом на чистоту кода, простоту и расширяемость.

**2. Цели проекта**

*   Создать легковесный, работающий прототип форума с интеллектуальной защитой от спама.
*   Реализовать весь функционал в рамках единого, цельного приложения.
*   Использовать единый технологический стек (Python, FastAPI, Redis) для бэкенда.
*   Заложить простую и понятную архитектуру для дальнейшего развития.

**3. Технологический стек**

*   **Бэкенд:** Python 3.11+, FastAPI.
*   **База данных:** Redis (для хранения векторов обучающей выборки и постов форума).
*   **Фронтенд:** HTML5, CSS3, JavaScript (без фреймворков).
*   **Шаблонизация:** Jinja2.
*   **Окружение:** Запуск Redis в Docker-контейнере.

**5. Функциональные требования**

**5.1. Бэкенд (FastAPI)**

*   **Модели данных (`models.py`):**
    *   `Post`: Модель поста, хранящегося в Redis (id, title, content, author, timestamp).
    *   `CreatePost`: Модель для создания нового поста (title, content, author).
    *   `ClassificationResult`: Модель для результата проверки на спам.

*   **API-методы (`main.py`):**
    *   `GET /`: Отдает главную страницу форума (`forum.html`), используя шаблонизатор.
    *   `GET /api/posts`: Возвращает список всех постов из Redis.
    *   `POST /api/posts`:
        1.  Принимает данные для нового поста.
        2.  Вызывает внутреннюю функцию классификации спама из `core/classification.py`.
        3.  Если пост классифицирован как спам, возвращает ошибку `403 Forbidden` с причиной.
        4.  Если пост легитимен, сохраняет его в Redis (через `db.py`) и возвращает `201 Created`.
    *   `POST /api/train`: Запускает в фоновом режиме процесс обучения модели из `core/training.py`.
    *   `GET /api/stats`: Возвращает статистику работы классификатора.

**5.2. Фронтенд**

*   **`forum.html`:**
    *   Единая страница, содержащая:
        *   Форму для создания нового поста.
        *   Контейнер для динамической загрузки и отображения списка постов.
        *   Область для вывода сообщений об ошибках.
*   **`script.js`:**
    *   При загрузке страницы делает GET-запрос на `/api/posts` и отображает их.
    *   При отправке формы делает POST-запрос на `/api/posts`.
    *   Обрабатывает как успешные ответы (обновление списка постов), так и ошибки (показ уведомления).
